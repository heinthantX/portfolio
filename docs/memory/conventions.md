# Conventions

## Motion: no sideways travel
Motion never moves left or right on its own. Use vertical, scale or opacity. The one exception: hero text blocks slide in from the side as they scroll in, and leave back to the same side (`slideFrom` in `SignalHero.tsx`). Intro, wave and finale text rise from below instead. Cursor parallax and user-triggered hover nudges (`translate-x-1` on "→") are allowed. Owner preference, see `docs/design/DECISIONS.md` D8, relaxed for entrance slides by D12.

## Scroll state stays out of React
Scroll progress is read in rAF or `useFrame` and never put in React state, so scrolling causes no re-renders. See `docs/specs/signal-hero.md`.

## Typecheck needs typegen on a fresh checkout
On a fresh checkout run `pnpm exec next typegen` before `pnpm typecheck`. `LayoutProps` is generated by Next and the typecheck depends on it.

## Chapter indices come from CHAPTER_IDS
Derive `CHAPTERS`, `LAYER_OFFSET` and `WAVE_CHAPTER` from `CHAPTER_IDS` in `src/features/signal-scene/timeline.ts`. Never hardcode a chapter index. Layer j is chapter `j + LAYER_OFFSET`, so `j + 1` would land on the wave. See `docs/specs/signal-hero.md`.

## Formation moves are per point
Move the formation by blending each point between its two endpoint world-space poses in the shader (`uMatA`/`uMatB`), each on its own stagger. Do not move a group transform: it shifts every point rigidly, so any side change slides the whole formation. See `docs/design/DECISIONS.md` D9.

## Scroll-linked text uses ScrollWords
Split text with `ScrollWords` (`src/components/site/scroll-words.tsx`), not per-word JS. `view` mode uses CSS view timelines. `driven` mode reads one `--reveal` variable that the frame loop writes, and only when it changes by more than 0.002.
- Match accent words after stripping case and punctuation from both the accent list and the words. Without that, "holds." never matches "holds".
- Blur applies only at ≥768px.
- Do not put `data-reveal` on a wrapper of a ScrollWords block; it double-fades.

See `docs/specs/scroll-words.md`.

## Chapter jumps go through goTo
Every chapter jump (rail, stack outline, layer grid, wheel) calls `goTo` from `useChapterSnap` (`src/features/signal-scene/useChapterSnap.ts`). Never call `lenis.scrollTo` directly for a chapter: a direct call fights the snap and skips the chapter pace (`STEP_S` 2s, `MIN_S` 1s since D15; set them with `NEXT_PUBLIC_CHAPTER_STEP_S` / `NEXT_PUBLIC_CHAPTER_MIN_S`, never by hardcoding). See `docs/specs/signal-hero.md` and `docs/design/DECISIONS.md` D10 and D15.

## Show skill breadth in copy, not in highlights
Do not highlight individual skill tags (no signal-coloured tag for MongoDB or NoSQL). The owner rejected that. Show breadth in the copy instead, e.g. "SQL and NoSQL: Postgres and MySQL for relational data, MongoDB for documents". Write MySQL, not MariaDB (MariaDB is a fork). See `docs/design/DECISIONS.md` D10.

## E2E against the prod server: kill the port first
`next start` keeps serving the old build after a rebuild, so stale chunks load and the canvas never mounts in e2e. Kill the port before restarting the server, then run the tests.

## Command menu placeholder is a test contract
The command menu input keeps the placeholder "Type a command or search...". The e2e tests rely on it, so change the copy only together with the tests. See `docs/specs/command-menu.md`.
